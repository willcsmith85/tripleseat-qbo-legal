# PRIVACY POLICY
## Tripleseat to QuickBooks Integration Application

**Last Updated:** January 31, 2026

This Privacy Policy describes how the Tripleseat to QuickBooks Integration application ("Application") handles data for Urban Canvas LLC d/b/a Culinary Canvas STL ("Company").

---

## 1. APPLICATION SCOPE

**Internal Use Only:**
- This Application is an internal business tool
- Used exclusively by Company employees and authorized personnel
- Not available to the public, customers, or third parties
- Processes only Company business data

---

## 2. INFORMATION THE APPLICATION ACCESSES

### From Tripleseat
The Application accesses the following Company data from our Tripleseat account:
- Event information (names, dates, locations, statuses)
- Customer/client contact information
- Financial data (invoice amounts, line items, categories, billing totals)
- Payment information

### From QuickBooks Online
The Application accesses the following Company data from our QuickBooks account:
- Customer records
- Invoice records
- Service item records
- Tax code settings

**Data Flow:**
All data flows directly between the Company's Tripleseat and QuickBooks accounts via their respective APIs. No data is transmitted to external parties.

---

## 3. INFORMATION THE APPLICATION STORES

### Local Storage Only
The Application stores minimal data locally on the Company's computer/server:

**Sync Log Database (`sync_log.db`):**
- Tripleseat Event IDs
- Sync timestamps
- Success/failure status
- Configuration settings

**Purpose:** Prevent duplicate invoice creation and track synchronization history

**Location:** Company's local system only - not transmitted externally

---

## 4. HOW THE APPLICATION USES INFORMATION

**Authorized Uses:**
a) Synchronize event data from Tripleseat to QuickBooks invoices
b) Prevent duplicate invoice creation
c) Validate data accuracy (tax calculations, category mappings)
d) Generate error reports for Company personnel
e) Send email notifications to Company accounting staff

**No External Sharing:** Company data is never shared with external parties, sold, or used for any purpose other than internal business operations.

---

## 5. DATA TRANSMISSION AND SECURITY

**Security Measures:**

**Encryption:**
- All API communications use HTTPS/TLS encryption
- Data transmitted between Tripleseat and QuickBooks is encrypted

**Authentication:**
- OAuth 2.0 for QuickBooks (industry standard)
- OAuth 1.0 for Tripleseat (industry standard)
- Access tokens stored securely on Company system

**Access Control:**
- Only authorized Company personnel can use the Application
- Requires valid Tripleseat and QuickBooks credentials
- Access managed by Company IT/management

**No Cloud Storage:**
- No Company data stored on external cloud servers
- All processing occurs on Company systems
- Sync logs stored locally only
